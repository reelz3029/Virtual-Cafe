# ☕ Somewhere — 해질녘 책방 카페

> 고양이가 되어 다른 사람들과 함께 조용히 공부하는, 따뜻한 가상 스터디 카페.

**Somewhere**는 "혼자 공부하지만 혼자가 아닌" 느낌을 주는 멀티플레이어 웹 공간입니다.
접속하면 해질녘 책방 카페의 빈 의자에 고양이로 앉게 되고, 같은 방의 다른 접속자들도
각자의 자리에서 함께 머뭅니다. 카페의 시간은 **현실 시간과 동기화**되어 아침엔 환한 햇살이,
저녁엔 노을이 창으로 들어오고, 밤이 되면 실내 조명이 켜집니다.

## ✨ 주요 기능

| 기능 | 설명 |
|---|---|
| 🏠 **단면 인형의집 공간** | 벽 2면이 열린 닫힌 카페 — 우드 체커 바닥, 책장, 카운터, 펜던트, 떠다니는 먼지 |
| 🌅 **실시간 시간대 조명** | 클라이언트 로컬 시간에 따라 태양 위치·색·하늘이 연속 변화. 19시대 노을 피크, 밤엔 실내 형광 점등 |
| 🪟 **진짜 뚫린 창** | 발광 텍스처가 아닌 실제 개구부 — 햇빛이 통과해 바닥에 빛 기둥을 만들고 창밖 풍경이 보임 |
| 🐱 **고양이 = 실제 접속자** | Firebase presence 기반. 같은 방 사람들이 좌석에 자동 배정되어 보임 |
| 🚪 **룸 샤딩** | 방 정원(16명)이 차면 자동으로 다음 방이 열림 — 원자적 슬롯 예약으로 정원 초과 불가 |
| 👀 **3가지 시점** | 둘러보기(아이소) / 내 자리(데스크 클로즈업) / 1인칭(드래그·방향키 둘러보기) |
| 🔄 **회전 동기화** | 내 캐릭터가 바라보는 방향이 다른 클라이언트에 부드럽게(보간) 반영 |
| 🔐 **로그인/세션** | Google 계정 또는 게스트 닉네임, 새로고침 자동 로그인 |
| 🛠 **개발자 디버그 패널** | 시각 강제(0~24h 슬라이더), 가짜 손님 추가/제거로 다인 환경 테스트 |

## 🕹 조작

| 입력 | 동작 |
|---|---|
| 하단 **둘러보기 / 내 자리 / 1인칭** 버튼 | 시점 전환 (부드러운 카메라 보간) |

## 🚀 시작하기

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 프로덕션 빌드
```

### Firebase 설정

`src/systems/firebaseConfig.js` 에 Realtime Database가 활성화된 Firebase 프로젝트 설정을 넣고,
콘솔 → Realtime Database → 규칙에 다음을 추가합니다:

```json
{
  "rules": {
    "presence":   { ".read": true, ".write": true },
    "roomCounts": { ".read": true, ".write": true }
  }
}
```

- `presence/{방}/{세션}` — 접속자 위치·방향. `onDisconnect`로 탭 종료 시 자동 정리
- `roomCounts/{base}/{방}` — 방 정원 슬롯 카운터 (트랜잭션 예약)

Firebase 미설정 시에도 단일 방·혼자 모드로 동작합니다.

### Google 로그인 (선택)

`src/systems/authService.js` 의 `GOOGLE_CLIENT_ID`를 본인 OAuth 클라이언트 ID로 교체하고,
Google Cloud Console에서 배포 도메인(개발 시 `http://localhost:5173`)을
**승인된 자바스크립트 원본**에 등록하세요. 게스트 로그인은 설정 없이 동작합니다.

### 룸 샤딩 — "한 방을 키우지 않고, 적당한 방을 여러 개"

현실 카페가 만석이면 2호점을 내듯, 방 하나의 정원을 16명(4테이블×4석)으로 고정하고
차면 다음 방(`cafe__room0` → `cafe__room1` → …)을 엽니다.

입장은 `roomCounts` 트랜잭션으로 **"정원 미달일 때만 +1"** 하는 원자적 슬롯 예약이라,
동시에 여러 명이 몰려도 정원을 절대 넘지 않습니다. 만석이면 abort 후 다음 방을 시도하고,
크래시로 슬롯이 반납되지 않은 드리프트는 실제 presence 인원으로 주기 보정됩니다.
방마다 무드 메타(1층·공용홀 / 2층·창가 / 다락방 …)가 부여됩니다.

### 좌석 배정 — 서버 없이 전 클라이언트 일치

같은 방 접속자 목록을 **id 기준 정렬** 후 순서대로 좌석에 앉히므로,
중앙 서버 없이도 모든 클라이언트가 동일한 배치를 봅니다.
혼자일 때는 분위기용 더미 고양이(단골·책벌레)가 빈자리를 채워줍니다.

### 시간대 조명

`SKY_KEYS` 키프레임(0·5·6.5·9·13·17·18.7·19.6·20.6·22·24시)을 연속 보간해
태양 색·세기·앰비언트·배경·창밖 하늘을 만들고, 태양은 06~20시 동안
동→천정→서(창측) 아치를 그립니다. `nightFactor`가 19.5시부터 실내 조명
(펜던트·카운터·천장)을 부드럽게 점등합니다. 시간은 클라이언트별 로컬 시간이라
동기화가 필요 없습니다.

## 🛠 디버그 패널

개발 모드(`npm run dev`)에서 백틱(`) 또는 우하단 🛠 버튼으로 열립니다.
프로덕션 빌드에서는 URL에 `?debug`를 붙여야 나타납니다.

- **시간** — "실시간 동기화"를 끄고 슬라이더로 0~24시를 스크럽하며 조명 변화를 확인
- **가짜 손님** — 실제 presence로 등록되는 더미 접속자를 추가/제거.
  모든 클라이언트에 보이고 방 정원에도 반영되므로, 혼자서 좌석 배정·만석·룸 샤딩까지 테스트 가능

## 📦 기술 스택

- **Three.js 0.165** — WebGL 렌더링 (퍼스펙티브 아이소뷰, ACES 톤매핑, PCFSoft 그림자)
- **Vite 5** — 개발 서버 & 번들
- **Firebase Realtime Database** — presence·룸 샤딩 (서버 코드 없음)
- **nanoid** — 게스트 id 생성
- 종이 질감(grain)·비네트는 CSS 오버레이, 고양이 이름표는 캔버스 스프라이트
